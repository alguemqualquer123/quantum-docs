## Credits

Quantum is maintained by **SR VINIX**, who publishes this fork and its documentation.

It is a fork of **Doriax Engine**, created and maintained by **Eduardo Doria**, which is
itself the continuation of **Supernova Engine** — the ECS, data-oriented runtime, editor
and export pipeline documented here come from that lineage. The engine source stays
under Eduardo Doria's MIT copyright, and every source file keeps its original
`(c) Eduardo Doria` header; the fork's own changes are credited in the repository's
`NOTICE.md` and `AUTHORS`.

See the upstream project at [github.com/doriaxengine/doriax](https://github.com/doriaxengine/doriax).

### Built with

Quantum integrates several open-source libraries, including:

| Library | Use |
| --- | --- |
| [Box2D](https://box2d.org/) | 2D physics |
| [Jolt Physics](https://github.com/jrouwe/JoltPhysics) | 3D physics |
| [Lua](https://www.lua.org/) | Scripting |
| [meshoptimizer](https://github.com/zeux/meshoptimizer) | Mesh detail-level (LOD) simplification |
